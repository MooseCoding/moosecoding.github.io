Iron is a Rust interpreter I wrote from 2024 to 2026. It has a lexer, parser, evaluator, functions, control flow, arrays, classes, and method dispatch. The standard library runs programs that use objects and I/O. The repo has example programs for those features.

The public GitHub repo was published after I had already been writing Iron. The 2024–2026 dates on this site are the work dates, not the date the repo was created.
